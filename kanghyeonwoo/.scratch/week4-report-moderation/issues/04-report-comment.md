# 04: 중복 방지를 포함한 댓글 신고 접수

**What to build:** 사용자가 댓글을 신고하면 당시 본문을 보존한 PENDING 신고를 생성한다. 게시글 신고와 같은 중복 방지 규칙을 적용한다.

**Blocked by:** 02: 중복 방지를 포함한 게시글 신고 접수; 03: 댓글 목록·본문 검색 및 페이징.

**Status:** resolved

- [x] POST /comments/{commentId}/reports에서 reporterId와 reason을 받고 HTTP 201 및 문자열 S201 코드로 신고 결과를 반환한다.
- [x] 존재하는 사용자·댓글만 허용한다. 본인 댓글 신고는 403, 없는 사용자·대상 및 숨김 댓글·숨김 게시글의 댓글 신규 신고는 404다.
- [x] 삭제 댓글 신고와 동일 사용자·동일 댓글 중복 신고는 409로 응답한다. 잘못된 입력은 400이다.
- [x] 본문 스냅샷과 COMMENT 대상 종류를 저장하고 기존 신고 접수 규칙 및 DB 유니크 제약을 재사용한다.
- [x] 다른 사용자의 동일 댓글 신고 및 같은 ID를 가진 게시글·댓글에 대한 별도 신고를 허용한다.
- [x] 접수·거절 정책과 동시 신고 시 1건 저장을 검증하고 Swagger를 갱신한다.

## Answer

댓글 신고와 스냅샷 보존을 구현했다. 본인·삭제·숨김·존재하지 않는 대상 검사와 동시 중복 신고 차단을 검증했다.
