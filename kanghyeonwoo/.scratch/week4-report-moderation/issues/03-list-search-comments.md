# 03: 댓글 목록·본문 검색 및 페이징

**What to build:** 특정 게시글의 댓글과 대댓글을 최신순으로 조회하고 본문으로 검색할 수 있다. 숨김·삭제 댓글은 원문을 노출하지 않으면서 관계를 유지한다.

**Blocked by:** 01: 게시글 목록의 공통 페이징 응답 적용.

**Status:** resolved

- [x] GET /posts/{postId}/comments에서 댓글·대댓글을 parentId가 있는 평평한 목록으로 반환한다. 부모가 다른 페이지에 있어도 parentId를 유지한다.
- [x] keyword가 없으면 목록, 있으면 해당 게시글의 댓글 본문을 부분 검색한다.
- [x] 공통 페이징 응답과 page·size 검증 및 최신순 정렬을 적용한다.
- [x] 댓글 ACTIVE/HIDDEN 상태를 도입하고 기존 댓글은 ACTIVE로 보정한다. 기존 isDeleted는 유지하고 삭제 표시를 우선한다.
- [x] 필요한 게시글 공개 상태를 보장하며 02와 같은 ACTIVE/HIDDEN 정의와 데이터 보정 정책을 사용한다. 없는 게시글 및 숨김 게시글은 404다.
- [x] 일반 목록에서 숨김·삭제 댓글은 안내 문구와 구분 가능한 상태를 반환한다. 원문을 노출하지 않는다.
- [x] 검색 결과에서 숨김·삭제 댓글은 제외한다. 필터를 DB 페이징 전에 적용하고 전체 건수도 같은 조건으로 계산한다.
- [x] 게시글별 범위, 대댓글 관계, 안내 문구, 검색 제외, 페이징·정렬·오류를 HTTP 테스트로 검증하고 Swagger를 갱신한다.

## Answer

게시글별 댓글 목록·본문 검색과 평평한 parentId 응답을 구현했다. 숨김·삭제 안내 문구, 검색 제외, 전체 건수·페이징을 검증했다.
