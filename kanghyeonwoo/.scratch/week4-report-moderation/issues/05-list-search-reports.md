# 05: 신고 목록·스냅샷 검색 및 필터

**What to build:** 사용자가 접수된 신고를 상태와 대상별로 찾고 신고 사유 및 당시 스냅샷을 검색해 검토할 수 있다. 대상이 삭제되어도 신고를 조회할 수 있다.

**Blocked by:** 01: 게시글 목록의 공통 페이징 응답 적용; 02: 중복 방지를 포함한 게시글 신고 접수.

**Status:** resolved

- [x] GET /reports에서 조건이 없으면 전체 신고를 공통 페이징 형식과 최신순으로 반환한다. 관리자 역할 검사는 추가하지 않는다.
- [x] status, targetType, targetId를 선택 조건으로 제공하고 함께 지정한 필터는 AND로 적용한다.
- [x] keyword는 신고 사유·제목 스냅샷·본문 스냅샷 중 하나라도 포함하면 일치한다. 현재 대상 원문을 검색하지 않는다.
- [x] 신고 ID, 신고자, 대상 종류·ID, 상태, 사유, 스냅샷, 생성 시각을 반환한다.
- [x] 대상 삭제나 원문 수정과 관계없이 보존된 신고 스냅샷을 반환하고 검색한다.
- [x] 필터를 DB 페이징 전에 적용하며 잘못된 상태·대상 종류·ID·페이징 입력은 400이다.
- [x] 복합 필터, 각 스냅샷 검색, 빈 결과, 전체 건수, 정렬 및 오류를 검증하고 Swagger를 갱신한다.

## Answer

신고 상태·대상 필터 및 사유·스냅샷 검색을 구현했다. 현재 원문과 구분해 검색하며, 삭제 후에도 스냅샷을 조회할 수 있음을 검증했다.

전체 테스트: 78개, 실패·오류·건너뜀 0개. Standards 및 Spec 리뷰의 확정 발견 사항은 각각 0개다.
