# 01: 게시글 목록의 공통 페이징 응답 적용

**What to build:** 게시글 목록과 제목 검색 결과에서 전체 건수와 페이지 정보를 같은 형식으로 확인할 수 있게 한다. 새 댓글·신고 목록에도 사용할 공통 페이징 규격을 제공한다.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 게시글 목록과 검색의 data를 items, page, size, totalElements, totalPages로 통일한다. 기존 배열 응답을 사용하는 테스트와 문서를 함께 변경한다.
- [x] page는 1부터 시작하고 size는 기본 10, 최대 100이다. 범위를 벗어나는 값은 400으로 응답한다.
- [x] 생성 시각 내림차순, ID 내림차순으로 정렬하고 필터링을 DB 페이징 전에 적용한다.
- [x] 정상 조회, 빈 결과, 검색 결과의 전체 건수, 페이지 경계, 잘못된 파라미터를 HTTP 테스트로 검증한다.
- [x] 기존 검색 이력 및 집계 검색량의 동작을 유지한다.

## Answer

게시글 목록·제목 검색의 공통 페이징을 적용했다. 댓글·신고 목록도 같은 규격을 사용한다. HTTP 테스트에서 전체 건수·빈 결과·페이지 경계·잘못된 파라미터를 검증했다.

전체 테스트: 78개, 실패·오류·건너뜀 0개. Standards 및 Spec 리뷰의 확정 발견 사항은 각각 0개다.
