# 04: 게시글 신고 접수 이관

**What to build:** 사용자가 게시글을 신고하면 신고 당시 내용이 보존되고, 같은 사용자가 같은 게시글을 반복 신고할 수 없다.

**Blocked by:** 02 — 게시글 대상 조회·작성자 확인을 위한 블로그 공개 포트.

**Status:** resolved

- [x] 게시글 신고 API의 경로와 기존 성공·오류 응답을 유지한다.
- [x] 신고 모듈이 신고 상태, 사유, 게시글 대상 ID와 신고 당시 제목·본문 스냅샷을 소유한다.
- [x] 게시글 존재·공개 상태·작성자 정보는 블로그의 공개 포트를 통해 확인한다.
- [x] 본인 게시글 신고를 거절하고, 같은 신고자·대상 조합은 DB 제약을 포함해 중복 생성되지 않는다.
- [x] 신고 접수의 상태와 스냅샷, 중복 및 동시 요청 동작을 모듈·DB 통합 테스트로 검증한다.
