# 02: 게시글 수정·삭제와 상태 규칙 이관

**What to build:** 게시글 작성자는 기존 권한에 맞게 게시글을 수정·삭제하고, 다른 모듈은 블로그의 공개 기능을 통해서만 게시글 상태를 변경할 수 있다.

**Blocked by:** 01 — 사용자 프로필과 게시글 생성·상세 조회 경계.

**Status:** resolved

- [x] 게시글 수정·삭제 API의 경로와 기존 성공·오류 응답을 유지한다.
- [x] 작성자 본인 확인과 게시글 상태 변경 규칙을 `blog` 도메인·유스케이스가 소유한다.
- [x] 게시글 숨김 기능을 다른 모듈이 사용할 수 있도록 공개 포트로 제공한다.
- [x] 다른 모듈의 JPA 엔티티·저장소에 직접 의존하지 않고 외부 식별자와 전용 레코드만 사용한다.
- [x] 기존 CRUD, 권한 거부, 숨김 후 조회 차단과 트랜잭션 동작을 검증한다.
