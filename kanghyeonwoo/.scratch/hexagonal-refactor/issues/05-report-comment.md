# 05: 댓글 신고 접수 이관

**What to build:** 사용자가 댓글을 신고하면 신고 당시 댓글 내용이 보존되고, 중복 신고와 신고할 수 없는 댓글 상태가 기존 정책대로 차단된다.

**Blocked by:** 03 — 댓글 대상·상태 공개 기능; 04 — 신고 접수 경계와 중복 정책.

**Status:** ready-for-agent

- [ ] 댓글 신고 API의 경로와 기존 성공·오류 응답을 유지한다.
- [ ] 신고 모듈이 댓글 대상 ID와 신고 당시 본문 스냅샷을 보존한다.
- [ ] 댓글·부모 게시글 상태 및 작성자 정보는 블로그의 공개 포트로 확인한다.
- [ ] 본인 댓글, 숨김·삭제 댓글, 숨김 게시글의 댓글 신고를 기존 정책대로 제한한다.
- [ ] 동일 신고자·대상 중복 및 동시 요청을 게시글 신고와 같은 데이터 소유 경계에서 검증한다.
