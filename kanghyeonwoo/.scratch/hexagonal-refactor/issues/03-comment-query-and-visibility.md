# 03: 댓글 목록·검색과 상태 규칙 이관

**What to build:** 사용자가 특정 게시글의 댓글과 대댓글을 기존 규칙에 따라 조회·검색하고, 숨김·삭제 댓글은 원문 대신 안내 상태를 확인할 수 있다.

**Blocked by:** 02 — 블로그 게시글 경계와 공개 상태 기능.

**Status:** resolved

- [x] 댓글·대댓글 목록 및 본문 검색 API의 경로, 페이징, 응답 필드를 유지한다.
- [x] 댓글 상태와 대댓글 관계를 `blog` 모듈이 소유한다.
- [x] 숨김·삭제 댓글의 안내 문구와 검색 제외, 숨김 게시글 댓글 조회 차단 동작을 유지한다.
- [x] 댓글 조회가 다른 모듈의 JPA 엔티티·저장소를 노출하지 않는 공개 계약을 사용한다.
- [x] 부모가 다른 페이지에 있는 대댓글, 잘못된 페이징, 숨김·삭제 상태를 API 및 모듈 경계 테스트로 검증한다.
