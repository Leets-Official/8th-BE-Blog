# 09: 게시글 목록·키워드 검색을 검색 프로젝션으로 전환

**What to build:** 사용자가 기존 게시글 목록 경로에서 최신 게시글과 키워드 검색 결과를 조회하고, 검색 데이터가 게시글 변경에 맞춰 갱신된다.

**Blocked by:** 08 — 검색 모듈의 저장·조회 경계와 기존 검색 동작.

**Status:** ready-for-agent

- [ ] 게시글 목록·키워드 검색 경로와 페이징·정렬·검색 기록 동작을 유지한다.
- [ ] 검색 모듈이 게시글 검색용 프로젝션과 키워드 조회 규칙을 소유하고 블로그 테이블을 직접 조회하지 않는다.
- [ ] 블로그의 생성·수정·삭제·숨김 변경을 검색 모듈이 게시글 변경 이벤트로 받는다.
- [ ] 현재 단일 애플리케이션에서는 이벤트와 프로젝션 갱신이 동기 처리되고 같은 DB 트랜잭션에 참여한다.
- [ ] 숨김 게시글 제외, 검색어 유무, 페이징, 검색 집계, 변경 이벤트 처리 실패 시 롤백을 검증한다.
