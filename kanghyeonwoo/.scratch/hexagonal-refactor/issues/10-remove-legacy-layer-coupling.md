# 10: 레거시 계층 결합 제거 및 전체 경계 검사 강화

**What to build:** 모든 기존 기능이 새 모듈 경계를 통해 동작하고, 이전 기술 계층 내부 객체를 직접 공유하지 않는다.

**Blocked by:** 09 — 게시글 검색 프로젝션과 기존 목록 경로의 최종 이관.

**Status:** resolved

- [x] 기존 컨트롤러·서비스·저장소 호출 경로 중 대체된 코드를 제거한다.
- [x] 다른 모듈의 JPA 엔티티·Spring Data 저장소 직접 참조가 남지 않는다.
- [x] ArchUnit 규칙을 전체 모듈에 적용해 domain/application/adapter 방향과 기능 경계를 강제한다.
- [x] 기존 API와 기존 DB 테이블·데이터, 신고·검색 상태 및 동시성 동작의 회귀 테스트가 통과한다. 검색 모듈은 요구된 검색 프로젝션용 신규 테이블만 추가하며 기존 테이블·데이터는 변경하지 않는다.
- [x] 모든 기존 기능이 새 모듈 경계로 이관되었음을 전체 테스트와 아키텍처 검사로 확인한다.
