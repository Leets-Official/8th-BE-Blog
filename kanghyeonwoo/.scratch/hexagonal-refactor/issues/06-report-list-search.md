# 06: 신고 목록·검색 이관

**What to build:** 사용자가 기존 신고 목록 API에서 상태·대상 조건으로 신고를 필터링하고 사유 및 신고 당시 스냅샷을 검색할 수 있다.

**Blocked by:** 05 — 게시글·댓글 신고 데이터와 스냅샷 계약.

**Status:** resolved

- [x] 신고 목록 API의 경로, 페이징, 응답 필드를 유지한다.
- [x] 상태·대상 종류·대상 ID 필터를 AND 조건으로 적용한다.
- [x] 키워드는 신고 사유와 제목·본문 스냅샷에서 검색하고 현재 원문에는 의존하지 않는다.
- [x] 신고자·처리자 ID는 공개 `UserId` 값으로 전달하며 JPA `User` 엔티티를 노출하지 않는다.
- [x] 빈 결과, 복합 필터, 페이징 전체 건수, 잘못된 조건을 API·저장소 통합 테스트로 검증한다.
