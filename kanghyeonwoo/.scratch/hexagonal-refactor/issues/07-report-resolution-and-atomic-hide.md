# 07: 신고 처리와 콘텐츠 숨김의 원자성 보존

**What to build:** 사용자가 신고를 KEEP 또는 HIDE로 처리하면 신고 상태와 콘텐츠 공개 상태가 함께 완료되거나 함께 롤백된다.

**Blocked by:** 05 — 두 대상 종류의 신고와 신고 상태 규칙.

**Status:** ready-for-agent

- [ ] 신고 처리 API의 경로와 기존 성공·오류 응답을 유지한다.
- [ ] 신고 모듈은 `PENDING → RESOLVED`를 소유하고, 이미 처리된 신고의 재처리를 거절한다.
- [ ] 블로그 모듈은 게시글·댓글 공개 상태를 소유하며 신고 모듈의 HIDE 명령을 공개 포트로 제공한다.
- [ ] KEEP는 현재 공개 상태를 유지하고 HIDE는 신고 대상만 숨기며, 다른 신고로 숨긴 대상을 복원하지 않는다.
- [ ] 신고 처리와 콘텐츠 숨김은 Spring 트랜잭션 데코레이터 아래 원자적으로 동작하고 실패 시 함께 롤백한다.
- [ ] 동시 처리, 삭제된 대상, 다른 신고로 이미 숨겨진 대상, KEEP/HIDE 경계 동작을 검증한다.
