# Java 코드 전반의 가독성 정리

요청: 일부 예시만 수정하지 말고 프로젝트 전체 Java 코드를 같은 기준으로 정리한다.
기준 커밋: `bdb5338`. 대상: main Java 236개 및 test Java 46개.

## 범위와 유지할 동작

- 컨트롤러의 서비스 호출, DTO 변환, HTTP 응답 생성을 분리한다.
- 와일드카드·미사용 import 및 불필요한 완전 수식 타입 이름을 정리한다. 같은 이름의 타입 충돌은 명시적 수식을 유지한다.
- 모호한 상태 변수명, 중첩된 캐시 갱신, 복잡한 정렬·거리 계산을 명확히 표현한다.
- 반복되는 프로필 변환과 검색 결과 행 매핑을 메서드로 모은다.
- 제어문 중괄호를 전체에 적용하고 PMD에 규칙을 추가한다. 미사용 지역변수도 검사한다.
- SQL 텍스트 블록은 실행 문자열을 유지하며 소스 들여쓰기를 정리한다.
- 공개 API 경로·응답 JSON·상태 코드, JWT 수명·회전·로그아웃 정책, 검색 순위·집계·동시성, 트랜잭션 경계를 유지한다.
- 기존 모듈 경계와 공개 포트를 유지한다.
- 각 단위를 관련 테스트로 검증하고 커밋하며, 마지막에 전체 check를 실행한다.
