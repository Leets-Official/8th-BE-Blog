# 기능별 웹 DTO 소유권 정리

Status: complete

## Problem

게시글·댓글·신고·검색의 HTTP 요청과 응답 DTO가 전역 `dto` 패키지에 섞여 있어 기능 모듈의 웹 경계와 데이터 계약의 소유자가 불분명하다. 공통 응답 래퍼와 기능별 API 모델도 같은 위치에 놓여 있다.

## Solution

- 공통 API 응답 래퍼와 페이지 응답은 `shared.web`이 소유한다.
- 게시글·댓글, 신고, 검색의 요청·응답 DTO와 공개 API enum은 각각 해당 기능의 웹 어댑터가 소유한다.
- 애플리케이션·도메인 계층은 웹 DTO를 참조하지 않는다.
- 전역 `dto` 패키지는 모든 모델을 이동한 뒤 제거하고, 기능 DTO가 다시 전역 패키지에 추가되지 않도록 아키텍처 규칙으로 막는다.
- 요청·응답 JSON, 경로, HTTP 상태 코드, 공통 응답 코드와 검증 동작은 유지한다.

## Ticket Sequence

01 공통 웹 응답 DTO 이동
02 게시글·댓글 웹 DTO 이동
03 신고 웹 DTO 이동
04 검색 웹 DTO 이동 및 전역 DTO 패키지 정리
