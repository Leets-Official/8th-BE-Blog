# 05: 개발용 예시 데이터 자동 삽입과 API 시연

**What to build:** 명시적으로 선택한 개발 데모 프로필로 실행하면 예시 작성자·게시글·검색어·이력·중복 판정 상태·분 단위 집계가 삽입되고 세 검색 API와 기존 게시글 검색을 즉시 시연할 수 있다.

**Blocked by:** 02, 04. 04가 03과 01에 의존하므로 중복된 선행 관계는 나열하지 않는다.

**Status:** ready-for-agent

- [ ] 예시: 검색어 8개, 이력 43개, 중복 판정 상태 43개, 분 단위 집계 8개. 실제 검색 결과와 사전 승격을 확인할 게시글·작성자 데이터도 함께 제공한다.
- [ ] 시간: 테스트는 예시 데이터 기준 시각으로 Clock을 고정한다. 개발 데모는 삽입 시각 기준 분 경계에 맞춰 모든 시각을 같은 간격만큼 이동하여 최근 순위가 나타나게 한다. 시간 이동은 테스트 세션의 중복 판정 시각에도 동일하게 적용한다.
- [ ] 멱등성: 기존 데이터는 덮어쓰거나 삭제하지 않고, 전용 데모 데이터의 안정적인 식별자로 중복 삽입을 막는다. 기본 프로필과 일반 테스트 실행에는 데모 데이터를 자동 삽입하지 않는다. 데모 데이터 재생은 일회성으로 하며 매 시작 시 검색 시각을 새로 갱신하지 않는다. 시간이 지나면 데모 순위도 자연스럽게 만료됨을 안내한다.
- [ ] 검증: 실제 DB 삽입 후 sprng → spring, 스프링부투 → 스프링부트·스프링, 급상승 spring → jpa → java 및 시간대별 통계를 API로 확인한다. 재시작 시 중복 없음, 기본 프로필에서 미삽입, 초기화 완료 후 BK-tree의 사전 반영을 확인한다.
- [ ] 문서: 데모 프로필 실행법, 쿠키를 유지한 검색 예시, 세 API 호출과 기대 결과, 고정 시각 테스트 및 데모 데이터 만료 동작을 설명한다.
