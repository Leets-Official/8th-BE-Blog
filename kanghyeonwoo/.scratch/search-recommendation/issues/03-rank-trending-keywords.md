# 03: 분 단위 집계를 이용한 급상승 검색어 API

**What to build:** 게시글 검색량을 분 단위로 누적하고 최근 60분의 급상승 검색어 상위 10개를 조회한다.

**Blocked by:** 01.

**Status:** resolved

- [x] 범위: 검색어별 분 단위 집계 테이블과 유니크 제약, 검색 이력·마지막 집계 시각·버킷 증가의 원자적 처리, 기존 이력의 버킷 초기 집계, 급상승 API, 30일이 지난 버킷 정리.
- [x] 규칙: 최근 60분 검색량 5 이상이고 직전 60분보다 증가한 검색어만 포함. 점수는 증가량을 직전 검색량과 5 중 큰 값으로 나눈다. 점수와 최근 검색량 내림차순 후 검색어 사전순으로 정렬한다. 결과 없는 검색어도 집계에 포함한다.
- [x] 정확성: 요청 시각을 한 번 고정하고 시작 포함·끝 제외로 계산한다. 전체 분은 버킷에서, 경계에 걸친 부분 분은 원본 이력에서 계산하여 원래의 60분 구간 정의를 유지한다. 초기 집계·재시작·동시 검색에서 누락이나 이중 집계가 없어야 한다.
- [x] 검증: 직전 검색량 0, 최소 검색량, 동점, 분·60분 경계, 이력과 버킷 합계 일치, 동시 요청, 재시작 및 기존 이력 보완, 빈 순위.
- [x] 독립성: 02의 추천 API나 BK-tree 구현은 선행 조건이 아니다.
