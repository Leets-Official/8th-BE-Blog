# 01: 게시글 검색 정규화와 세션별 검색 이력 기록

**What to build:** 정규화한 검색어로 기존 게시글 검색을 실행하고 유효한 첫 페이지 요청을 세션별로 중복 없이 기록한다. 재시작해도 검색 이력이 유지된다.

**Blocked by:** 없음.

**Status:** ready-for-agent

- [ ] 범위: 파일 기반 H2, 테스트 DB 격리, 기존 제목의 정규화 및 기존 데이터 보완, 검색어·검색 이력·중복 집계 상태 테이블, 서버 세션 쿠키, 검색어 사전 등록 조건.
- [ ] 검증: NFC·대소문자·공백·리터럴 포함 검색, 2~50자 검증, 빈 검색어 목록과 후속 페이지 제외, 결과 없는 검색 집계, 5분 경계, 동시 중복 요청, 사전 승격, 파일 DB 재접속, 기존 게시글 CRUD 회귀.
- [ ] 수명주기: 검색 이력의 30일 보관과 오래된 중복 판정 상태 정리까지 포함한다. 입력 검증과 게시글 검색 실패 시에는 검색량을 남기지 않는다. 추적 저장 실패 시 부분 기록 없이 요청을 실패 처리한다.
