# 04: 검색어별 최근 24시간 통계 API

**What to build:** 특정 검색어의 최근 24개 시간대별 검색량과 최근·직전 60분 검색량 및 상승 점수를 조회한다.

**Blocked by:** 03.

**Status:** resolved

- [x] 범위: 분 단위 집계에서 시간 단위 통계를 생성하고, 60분 비교는 03과 같은 계산 규칙을 공유한다.
- [x] 규칙: Asia/Seoul 기준 현재 시간대를 포함해 시간순 24개 구간을 반환한다. 빈 구간은 0, 현재 구간은 요청 시각까지의 부분 집계로 표시한다. DB 시각은 UTC. 미존재 검색어 ID는 404, 이력이 없는 등록 검색어는 0을 반환한다.
- [x] 검증: 고정 Clock에서 24개 구간, 시간대와 날짜 경계, 0 채움, 현재 부분 구간, 미존재 ID, 급상승 API와 동일한 집계값. 통계 조회는 검색량을 만들지 않는다.
