# 02: BK-tree 기반 유사 검색어 추천 API

**What to build:** 초기 사전 및 검색으로 추가된 사전 단어에서 철자가 비슷한 검색어를 최대 5개 추천한다.

**Blocked by:** 01.

**Status:** resolved

- [x] 범위: 시작 시 DB 사전으로 BK-tree 구성, 초기 단어 멱등 등록, 커밋 후 신규 사전 반영과 갱신 실패 시 재구성, 동시 탐색·변경 처리, 추천 API와 공통 응답·입력 검증.
- [x] 규칙: 입력 2~4자는 거리 1 이하, 5~50자는 거리 2 이하. 동일 단어 제외. 편집 거리, 최근 1시간 집계 검색량, 검색어 사전순으로 정렬한다. 최근 검색량은 이 단계에서 원본 이력으로 집계할 수 있다.
- [x] 검증: 한글·영문 오타, 빈 후보, 임계 거리, 동점, 전체 사전 편집 거리 계산과 후보 일치, 재시작과 사전 추가 반영. 추천 요청 자체는 검색량을 생성하지 않는다.
