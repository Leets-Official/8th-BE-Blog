# 실패 응답 생성 인터페이스 정리

Status: ready-for-agent

## Scope

[명세](../spec.md)에 따라 데이터를 받는 실패 생성 메서드의 사용처를 확인하고, 오류 응답의 `data: null` 계약에 맞춰 불필요한 오버로드를 제거한다.

## Completion criteria

- 사용처 확인 결과를 기록하고 필요한 호출부를 두 인자 실패 생성 메서드로 이전한다.
- 지원하는 실패 생성 경로와 대표 HTTP 오류 응답에서 명시적인 `data: null`을 검증한다.
- 성공 응답과 기존 의미 코드·HTTP 상태 매핑을 유지한다.
- 전체 테스트가 통과하며 응답 객체 전체 구조를 개편하지 않는다.
