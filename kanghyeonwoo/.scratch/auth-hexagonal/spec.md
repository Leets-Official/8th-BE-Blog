# Auth 헥사고날 리팩터링

Status: Implemented

기준 커밋: a6c98ad. 브랜치: 강현우/6주차.

## 요구사항

- auth 코어의 웹 응답 코드·Spring·JPA·JJWT·구체 어댑터 의존 제거.
- 입력/출력 포트, 도메인 상태 모델·업무 예외, 독립된 유스케이스, 명명된 어댑터와 조립 설정으로 분리.
- 새 경계를 먼저 추가하고 기능별로 이전한 뒤 기존 구조와 임시 연결 제거.
- HTTP 경로·상태·JSON 필드·오류 메시지·Swagger 토큰 스키마 유지.
- DB 테이블·컬럼·기존 로그인 및 OAuth 티켓 호환성 유지.
- Access 10분, 회전 Refresh 7일, 여러 기기, 로그아웃 후 남은 Access 정책 유지.
- 동시 재발급 하나만 성공, 이전 Refresh 재사용 시 계열 폐기 및 거절 응답에서도 커밋 유지.
- 카카오 state·브라우저 연결·일회용 코드·중복 계정·이메일 정책과 실제 REST 연결 유지.
- 테스트 경계: 입력 포트의 격리 단위 테스트, 기존 MockMvc API 및 외부 REST 계약, ArchUnit 의존 검사.
- 티켓별 검증 및 커밋. 마지막에 두 축 코드 리뷰 및 전체 ./gradlew check.

## 검증 결과

전체 `./gradlew clean check --console=plain` 성공. 테스트 130개, 실패·오류·건너뜀 0개. Standards/Spec 리뷰 각 지적 0건. 실제 카카오 로그인은 외부 앱 설정 후 확인한다.
