# 로그인별 Refresh Token 회전과 재사용 시 전체 폐기

여러 기기의 로그인을 독립적으로 유지하기 위해 사용자당 하나의 Refresh Token 대신 로그인별 토큰 계열을 관리한다. 이전 토큰 재사용은 공격자가 먼저 새 토큰을 얻은 상황일 수 있어 해당 계열 전체를 폐기하며, 정상 클라이언트의 동시 재발급도 같은 정책을 적용하므로 클라이언트는 재발급을 한 요청으로 합쳐야 한다. Access Token은 로그아웃 후에도 최대 10분 유효하도록 하고 별도 블랙리스트를 두지 않으며, Refresh Token은 회전 때마다 다시 7일 유효하도록 합의했다.
