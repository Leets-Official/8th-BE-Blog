# 모듈러 모놀리스에서 헥사고날 경계를 세운다

현재는 하나의 Spring Boot 애플리케이션과 하나의 DB를 유지하면서 `user`, `blog`, `report`, `search` 모듈을 기능별로 분리한다. 각 모듈은 도메인·유스케이스·포트·어댑터 경계를 지키고 자기 데이터와 저장소를 소유하며, 모듈 간 호출은 공개 포트와 불변 계약만 사용한다. 이 방식은 기존 API·DB 동작과 신고 처리 원자성을 보존하면서 경계부터 검증할 수 있고, 실제 독립 서비스 추출 시 별도 DB·이벤트 전달·분산 보상 설계를 미리 강제하지 않는다. 서비스 추출 시 데이터 이관과 네트워크 통신 방식은 별도 결정한다.
