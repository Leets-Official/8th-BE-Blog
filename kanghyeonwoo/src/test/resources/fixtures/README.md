# 검색 예시 데이터

예시 fixture의 단일 원본은 main resources의 `demo/search-example.json`이다. 데모 프로필과 통합 테스트가 이 리소스를 공유하며 SearchDemoSeeder가 실제 DB에 삽입한다. 실행법은 [4주차 검색 문서](../../../../docs/week4-search.md)를 참고한다.

## 기준 시각

- 테스트 Clock: `2026-10-26T06:00:00Z` (한국 시각 15:00)
- 최근 구간: 한국 시각 `[14:00, 15:00)`
- 직전 구간: 한국 시각 `[13:00, 14:00)`
- 실제 현재 시각으로 실행하면 아래 순위와 일치하지 않는다. 개발용 데모 로더를 만들 때는 모든 시각을 같은 간격만큼 이동하고, 테스트에서는 고정 Clock을 사용한다.

## 데이터와 기대 결과

검색어 8개, 집계된 검색 이력 43개, 세션별 마지막 집계 상태 43개, 분 단위 집계 행 8개를 포함한다. 각 이력은 서로 다른 테스트 세션에서 발생한 것으로 구성했다.

| 검색어 | 추천 사전 | 직전 검색량 | 최근 검색량 | 급상승 결과 |
|---|---|---|---|---|
| spring | 포함 | 2 | 10 | 1위, 점수 1.6 |
| jpa | 포함 | 0 | 6 | 2위, 점수 1.2 |
| java | 포함 | 4 | 8 | 3위, 점수 0.8 |
| 스프링부트 | 포함 | 5 | 5 | 증가하지 않아 제외 |
| sprng | 제외 | 0 | 3 | 최소 검색량 미달 |
| spring boot / 스프링 / 자바 | 포함 | 0 | 0 | 검색 이력 없는 사전 단어 |

추천 기대 결과:

- `sprng`: spring(거리 1)
- `스프링부투`: 스프링부트(거리 1), 스프링(거리 2)
- `zzzzz`: 빈 목록

`expected`는 고정 시각 API 테스트의 기대값이다. spring의 시간대별 통계는 13시에 2회, 14시에 10회이며 나머지 시간은 0이다. 현재 15시 구간을 포함해 총 24개 시간대를 반환한다.

JSON은 검색 데이터를 정의한다. 데모 로더가 작성자와 게시글도 함께 삽입하여 기존 게시글 검색을 시연할 수 있다.
