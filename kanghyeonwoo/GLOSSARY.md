# 블로그 검색

게시글 검색과 검색어 추천에서 사용하는 용어를 정의한다.

## Language

**유사 검색어**:
입력한 검색어와 철자가 비슷한 검색어. 의미가 비슷하다는 뜻은 아니다.
_Avoid_: 연관 검색어, 동의어

**검색어 사전**:
추천 대상으로 등록된 검색어의 집합. 초기 등록 검색어와 실제 게시글 검색 결과가 있는 검색어를 포함한다.

**정규화 검색어**:
같은 검색어를 일관되게 식별하도록 표기를 통합한 검색어. 영문 대소문자, 앞뒤 공백과 연속 공백의 차이를 구분하지 않으며 단어 사이 공백의 유무는 구분한다.

**검색 이력**:
사용자가 게시글 검색을 실행한 기록. 검색어 사전에 등록되는지와 별개로 기록한다.

**급상승 검색어**:
최근 1시간의 검색량이 직전 1시간보다 증가한 검색어. 전체 누적 검색량 순위와 구분한다.
_Avoid_: 인기 검색어

**집계 검색량**:
검색 순위와 통계에 반영하는 검색 횟수. 자동완성 요청과 같은 세션에서 같은 검색어를 5분 안에 반복 검색한 요청은 제외한다.

**검색 세션**:
익명 사용자의 연속된 검색을 구분하는 단위. 같은 검색 세션에서 같은 정규화 검색어를 반복 검색하면 중복 집계 제외 규칙을 적용한다.

**분 단위 검색량**:
특정 검색어에 대해 한 분 동안 집계된 검색 횟수. 급상승 검색어와 시간대별 통계의 집계 근거다.

## 사용자 및 콘텐츠

**사용자 프로필**:
게시글·댓글 작성자와 신고자·처리자를 식별하는 이름·이메일 정보. 이 프로젝트에서 사용자 프로필은 인증 계정을 뜻하지 않는다.

## API 및 오류

**HTTP 상태**:
HTTP 응답이 요청을 처리한 결과를 나타내는 표준 상태값. 응답 본문의 업무 결과 코드와 구분한다.

**응답 코드**:
성공 또는 구체적인 오류 종류를 클라이언트가 식별하는 코드. HTTP 상태와 별개이며, 메시지 문구가 바뀌어도 같은 의미를 유지한다.
